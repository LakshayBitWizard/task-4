# ⚡ Task Manager Dashboard

A premium, fully-featured **Task Manager Dashboard** built with pure HTML, CSS, and JavaScript. This project implements a complete CRUD (Create, Read, Update, Delete) system with LocalStorage persistence, real-time search, and status filtering.

> **MainCrafts Full Stack Web Development Internship — Task 4**

---

## ✨ Features

- **Add Tasks** — Quickly add new tasks with a clean input form
- **Edit Tasks** — Inline editing with save/cancel controls
- **Delete Tasks** — Remove tasks with smooth slide-out animation
- **Mark as Completed** — Toggle tasks complete/pending with animated checkboxes
- **LocalStorage Persistence** — Tasks survive page refreshes
- **Real-time Search** — Filter tasks instantly by name
- **Status Filter** — View All, Completed, or Pending tasks via dropdown
- **Dashboard Stats** — Live counters for Total, Completed, and Pending tasks
- **Toast Notifications** — Feedback on every action
- **Fully Responsive** — Works on mobile, tablet, and desktop

## 🎨 Design

- Dark glassmorphism aesthetic with frosted-glass panels
- Gradient accent colors (cyan → purple)
- Micro-animations on hover, add, delete, and checkbox toggle
- Custom scrollbar and animated background orbs
- Modern Inter font from Google Fonts

## 🚀 How to Run

1. Clone or download this repository
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge)
3. Start adding tasks!

No build tools or dependencies required — it's pure HTML, CSS, and JavaScript.
